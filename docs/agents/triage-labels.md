# Triage labels

The skills' five triage roles map one-to-one to labels of the same name: `needs-triage`,
`needs-info`, `ready-for-agent`, `ready-for-human` and `wontfix`.

The other v11 labels:
- **Kind:** `bug`, `feature`, `perf`, `research`, `docs`, `chore`, `security`, `fairplay`
- **Area:** `area:core`, `area:sim`, `area:strategy`, `area:learn`, `area:runtime`, `area:web`,
  `area:tooling`, `area:ci`
- **Wayfinder:** `wayfinder:map`, `wayfinder:task`, `wayfinder:research`, `wayfinder:grilling`,
  `wayfinder:prototype`
- **Process:** `agent-claimed` and `v11`

Class-aware fit on one season snapshot

Question. Does a per-opponent read, gated by the opponent's adaptivity class and a budget share, earn enough trustworthy evidence over one season to build — and what does the online fit cost? This page mirrors the repo's rules: a 30-hand evidence floor, trust n/(n+30), class budgets (Fixed 1, Switching 1, Learning 0.25, Unknown 0), prior 20, and a drift reset at a change point.

Measured verdict · NO-GO for the class gate

NO-GO for the class-aware gate as designed; GO for the underlying per-opponent read.

On the measured snapshot the read is 0.0594 nats/action better than the population model (well past the repo's 0.005 fit margin), but the class gate is 0.0192 nats/action worse than the same read without classes. The current in-play gate fires for 5 of 195 opponents and only 0.0028 nats/action. The online update is cheap: about 19 µs per opponent-hand. The blocker is evidence and gating, not compute.

Why the class gate loses

Unknown is a volume class, not a behaviour. 65 of 195 opponents never reach 60 hands, so they stay unknown for the whole season; they still supply 17,225 actions (38%). The design gives unknown a zero budget, so the class-aware estimate is exactly the population model for them — while the class-blind read is 0.049 nats/action better on those very actions.

The class layer has little room to help. Only 2 opponents are learning and 1 is switching. The learning test needs 60 hands where the opponent faced our bet; the whole season contains only 3,222 such observations, a median of 10 per opponent.

The current gate uses almost none of it. Fixed + at least 30 preflop-facing actions + a raise share above 40% admits 5 opponents and 413 of 5,201 hands. That is why the in-play gate is 0.0028 nats/action better than population, below the 0.005 margin. It also requires Fixed, so the Learning and Switching budget shares never reach a decision today.

allOneReset equals class-blind exactly: the one switching opponent's reset has no measurable likelihood effect (18 actions after the change). A positive Unknown budget recovers most of the loss but never turns the class layer into a win. The class layer's case has to be an exploit-loss case, not a likelihood case — and this snapshot has only 3 opponents on which to measure it.

5. Go / no-go

Recorded decision

NO-GO for the class-aware gate as designed; GO for the underlying per-opponent read.

Build the per-opponent read: it is cheap (≈19 µs per opponent-hand in JS) and 0.0594 nats/action better than population on held-out actions. Do not build the class gate as specified: the zero budget for Unknown makes it 0.0192 nats/action worse than the same read without classes, and the current Fixed-only in-play gate uses 5 of 195 opponents and 413 of 5,201 hands.

What would change the answer

  • Separate evidence from class. Let the read earn trust before the class is known; use class as a cap or damping on top, not an on/off gate. Measured: Unknown 0.5 recovers 0.9660 nats/action, but still loses to class-blind 0.9591.
  • Widen the in-play gate. Only 5 opponents pass it today. Any read worth building needs a gate that uses the 128 opponents at trust ≥ 0.5 and 98 at trust ≥ 0.75.
  • Measure exploit loss, not only action log-loss. The Learning damping is a safety choice. This snapshot has 2 learning and 1 switching opponent, so safety cannot be demonstrated; the exploit gate is the right instrument, and this prototype cannot replace it.
  • Re-run on a richer season. The learning test needs 60 hands facing our bet; the season has a median of 10 per opponent. More live hands, or a name-bearing history export, would change the evidence base.
